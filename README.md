# N6 Shield ADIN2111: in development, nothing designed yet

Branch `n6-shield`, started 2026-11-17. A shield for the back of the N6 board with Sofar's Bristlemouth mote
circuit, a 5 V supply and the motor driver, as small as possible.

**Read `BRIEF.md` first.** The project in `N6_Shield_ADIN2111/` is still an unchanged copy of the Pi Zero
side-entry shield (branch `pi-zero-side-entry`); it is the starting point, not an N6 design. Do not build it.

Docs, tools, references and the history of the Pi shields are on the `development` branch (`START_HERE.md`).
