**Risks for later sprints (no action in S2):**
- **S5 / D11 pull-ups:** the Pi has its own pull-ups on GPIO2/3 (Raspberry Pi documentation states 1.8 kΩ fixed — cite a primary source in S5); 4.7 kΩ in parallel → ≈1.3 kΩ. The pull-ups go to the *shield's* 3V3 while the Pi has a separate 3V3 rail: if one rail is up and the other down, current can back-power through pull-ups/IO clamp diodes (same applies to the ADIN SPI/control lines). S5 should choose the pull-up rail and document power sequencing.
- **Layout (Nick):** the 2×20 socket mates from the shield's underside → J1 goes on B.Cu; check pin-1 orientation against the Pi.
- **S5 pin choice:** keep pins 27/28 (ID_SD/ID_SC, HAT EEPROM) unassigned unless HAT ID is implemented.
- **VBUS_OUT** previously fed P1 pins 14/16/18 (payload power); it now has no external outlet until S5's 2-pin connector.
